# The Lot (web)

The Lot is a simple free music streaming platform for recorded live concerts —
built on the open-source [Relisten](https://relisten.net) web project.

## Development

### To run
```
  #### install node
  #### install pnpm (npm i -g pnpm)
  $ pnpm i
  $ npm start
```
